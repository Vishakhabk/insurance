# Test Strategy

## Test layers
- Unit tests
- API and contract tests
- Integration tests
- End-to-end workflow tests
- UI accessibility tests
- Security tests
- Performance and resilience tests
- Data migration and reconciliation tests
- Regulatory and compliance rule tests
- Disaster recovery tests

## Insurance-specific scenarios
- Quote recalculation after risk changes
- Policy issuance with missing or invalid KYC
- Premium rounding and tax calculation
- Duplicate payment callback
- Backdated endorsement
- Cancellation during free-look period
- Grace period and lapse behavior
- Reinstatement eligibility
- Claim outside coverage period
- Claim exceeding sum insured
- Duplicate claim submission
- Fraud flag routing
- Approval delegation and segregation of duties
- Policy and claim document version mismatch
- Unauthorized access to another customer's policy
- Audit log immutability
