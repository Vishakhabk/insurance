# UX/UI Design Prompt

## Product context
## Target persona
## Journey / workflow
## Screens required
For each screen define:
- Purpose
- Entry points
- Components
- Fields and validation
- Loading, empty, success, and error states
- Permissions and role variations
- Accessibility
- Responsive behavior
- Offline behavior, if applicable
- Analytics events
- Navigation and exit conditions

## Important
Design only the selected epic and its explicitly linked work items. Do not introduce unrelated capabilities without labeling them as dependencies or assumptions.
